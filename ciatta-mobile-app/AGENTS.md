# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

# Copy

Never use an em dash (—), en dash (–), or hyphen (-) in user-facing copy. Run every remote or templated string through `displayCopy()` in `src/lib/displayCopy.ts` before it can render. Compound words become separate words (`heart rate`, not `heart-rate`).
